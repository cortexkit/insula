## New

- **Model scope on quota windows.** Each window can now carry `modelScope`: `all` when every model the account uses counts against it, or `subset` when only some models do and the provider doesn't list which. A window without it means insula couldn't tell. For example, Claude's weekly window is `all` and its Fable window is `subset`; every Antigravity pool is `subset`; Codex's weekly window is `all`. The per-provider table is in the consumer contract.

## Platforms

macOS (Apple silicon and Intel, signed and notarized), Linux (x64 and ARM64) and Windows (x64 and ARM64).
