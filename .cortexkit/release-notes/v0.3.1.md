insula 0.3.1 lets apps tell an earlier saved reset from a new one. It needs CortexKit core 0.21.3 or newer.

## For apps and other modules

- Every `usage.use_saved_reset` success reply now carries `redeemed_at`, the time the outcome was first decided, in the same form as `last_reset_at`. A new reset carries about the time of the request. A retried `request_id` returns its stored answer, spends nothing, and carries the original time. So a reply whose `redeemed_at` is earlier than its request is an earlier reset finishing. Error replies are unchanged. Samples are tagged `quota-phone-v3.1`.

## Platforms

macOS (Apple silicon and Intel, signed and notarized), Linux (x64 and ARM64) and Windows (x64 and ARM64).
