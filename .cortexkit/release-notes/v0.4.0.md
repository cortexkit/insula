insula 0.4.0 adds TrustedRouter, reads more providers from CodexBar v0.85.0, shows Ollama's older-plan limits, and keeps the saved-reset development bypass out of release builds. It needs CortexKit core 0.21.3 or newer.

## New providers

- **TrustedRouter** key budget from `apikey:trustedrouter`. The reported remaining budget and the key's limit, in exact microdollars. A key with no limit shows as an unlimited pool with no amounts. One key per computer.

## Provider updates

- **Ollama** older plans: the API key reply's 5-hour and weekly limits now show as `primary` and `secondary`, the same slots the settings page uses. Thanks to @lexomis for this one (#44). A remaining percent that is out of range or not a number now drops only that window, not the whole reading.
- **MiMo** Token Plan quota from an API key: `apikey:xiaomi-token-plan-cn` (China) or `apikey:xiaomi-token-plan-sgp` (Singapore). The key's family picks the region, and a key, when present, serves the row instead of the browser login. A count above its total means overage.
- **SiliconFlow China** reads the console balance from a deposited `cookie:cloud.siliconflow.cn` login when no China key is present. Remove a retired China key to use the console.
- **MiniMax** shows an exact "invalid api key" reply as `credential_rejected` instead of a generic failure.
- **TypeSafe** sends the console's same-site headers, so the billing balance stays readable behind TypeSafe's newer check.

## Fixes

- **Saved-reset development bypass** (#45): release builds no longer read `CK_INSULA_DEV_LOCAL_SAVED_RESETS`. Only a developer build compiled with the `dev-local-saved-resets` feature does. Health gains `devLocalSavedResets`, so anyone can confirm it is off. Thanks to @iceteaSA for the report.

## Platforms

macOS (Apple silicon and Intel, signed and notarized), Linux (x64 and ARM64) and Windows (x64 and ARM64).
