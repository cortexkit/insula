insula 0.4.4 names Antigravity's catalog provider. It needs CortexKit core 0.21.3 or newer.

## Changes

- **Antigravity readings carry `apiProvider: "google"`.** The model catalog lists Antigravity's models under `google`, so apps and modules that match quota to models can now match Antigravity's pools too. Plain Gemini API keys also use `google`; tell the two apart by `provider`.

## Platforms

macOS (Apple silicon and Intel, signed and notarized), Linux (x64 and ARM64) and Windows (x64 and ARM64).
