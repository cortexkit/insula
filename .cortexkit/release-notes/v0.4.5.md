insula 0.4.5 fixes the findings of an outside security and correctness audit. It needs CortexKit core 0.21.3 or newer.

## Security

- **Vault Codex sign-ins go only to OpenAI.** A server address set in the Codex CLI's settings file no longer receives the sign-in token of vault Codex accounts. The local Codex login still honours it.
- **Error text no longer carries credentials.** A provider refusal that echoes the request's credential, or any token-shaped value, is redacted before it reaches quota readers, health or logs.

## Saved resets

- **A settings file insula can't read turns automatic resets off** until it is fixed. Other settings keep their last good values.
- **The 30-minute limit holds for retried requests.** An old unfinished reset request can no longer be sent right after a newer reset on the same account. A new press on the phone or desktop finishes the older request under its original id instead of starting another.
- **Claude reset retries keep their reset.** A retry after a restart uses the same saved reset the first try named.

## Polling and readings

- Accounts waiting on a new sign-in no longer crowd a healthy account of the same provider out of polling.
- A login that fails right after it was replaced backs off again instead of being retried every turn.
- Reply readings can no longer lower a window's usage through an earlier reset time or many small steps.
- JetBrains readings carry the time the IDE wrote them, so old files show as old.
- OpenCode reports several workspaces as ambiguous instead of picking one.
- `usage.watch` announces an account that disappears.
- MiniMax shows no reset time when it can't tell the countdown's units.
- DeepSeek reports a broken local login store as unreadable, not as "not signed in".
- A tiny negative Codex balance stays negative.

## Robustness

- Grok replies have a nesting and work limit.
- Local login and state files are read with a 4 MiB cap, and only if they are regular files (links to regular files still work), so a huge or special file can't exhaust memory or stall polling.

## Platforms

macOS (Apple silicon and Intel, signed and notarized), Linux (x64 and ARM64) and Windows (x64 and ARM64).
