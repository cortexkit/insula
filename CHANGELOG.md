# Changelog

The public changelog is [GitHub Releases](https://github.com/cortexkit/insula/releases).
Each release has curated upgrade notes, provider changes, fixes, supported
platforms and the minimum CortexKit core version.

Release bodies are kept in [`.cortexkit/release-notes/`](.cortexkit/release-notes/).
See the [notes format](.cortexkit/release-notes/FORMAT.md) and
[release procedure](docs/releasing.md) when preparing a release.
