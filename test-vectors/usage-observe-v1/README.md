# usage.observe v1 wire vectors

Synthetic identities only. Requests and replies are the JSON frame body bytes, without a trailing newline, produced and decoded by insula's real usage.observe handler. Each pair starts from a successful poll with a 300-minute primary and 10080-minute secondary window. Each request includes an unknown credential (or account for legacy routing) to pin ignored-row encoding. The frame sample includes limit_reached: true; that flag is deliberately ignored.

Writers forward Claude's anthropic-ratelimit-unified-* headers. The Codex header allowlist is every x-codex-* header except x-codex-turn-state, plus x-*-primary-*, x-*-secondary-* and x-*-limit-name. Insula parses only the default x-codex-* family and ignores the rest. The broca-codex-headers request includes a non-default family that cannot override the default weekly window.

Pairs: broca-codex-headers, broca-codex-frame, claustrum-vouched-claude, legacy-routing. The modern key is credentialId; optional account must match the selected slot's resolved vault account id. Only reserved:claustrum may vouch, and every Claustrum row must include vouched principal and credentialId: the relay attests that it admitted that enrolled principal to report this credential. The vouched principal is diagnostic only; vouched.credentialId must equal the row's credentialId. Legacy account-only rows are accepted only from reserved:prefrontal-routing. The result is wrapped in result by the transport.

SHA256SUMS covers every other file, in shasum -a 256 format. Verify with shasum -a 256 -c SHA256SUMS. Regenerate with INSULA_WRITE_VECTORS=1 cargo test -p quota-module --bin ck-insula committed_usage_observe_vectors_match. The drift test compares generated bytes and checksums and refuses unexpected files.
